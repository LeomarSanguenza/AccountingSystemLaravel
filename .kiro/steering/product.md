# Product Overview

This is a financial management system built for government or organizational use, focusing on disbursement processing, obligation management, and financial tracking.

## Core Features

- **Disbursement Management**: Create, approve, process, and track financial disbursements
- **Obligation Requests**: Handle obligation request processing and tracking
- **Journal Entries**: Manage accounting journal entries for financial records
- **Employee Management**: Track employee information and roles
- **Role-Based Access Control**: Comprehensive permission system using Spatie Laravel Permission
- **System Tools**: Administrative tools for managing reference data (banks, barangays, payees, etc.)

## Key Business Entities

- **Users**: System users with role-based permissions and fund type assignments
- **Disbursements**: Financial disbursement records with approval workflows
- **Obligations**: Obligation requests and entries
- **Journals**: Accounting journal headers and details
- **Employees**: Employee records and management
- **Reference Data**: Banks, barangays, payees, signatories, offices, expense types, fund types

## User Roles & Permissions

The system implements granular permissions for:
- User management
- Disbursement operations (view, create, edit, delete, approve, process)
- Obligation management
- Employee management
- Journal management
- System administration
